**Configurable daily game selections.** Administrators can add the same game more than once with different option sets while a day still uses each game at most once. Game selections can also choose the game's own settings (for example Sudoku Auto notes, hints or timer and the Nonogram timer). The add flow uses a dedicated game-selection screen with switches for true/false game settings, and a compact Game content list with remove-only rows. The confusing Prepare now action was removed; test environments expose a Generate new daily challenges action for generation testing. Challenge settings now save reliably, and Administration is organized into Backups, Users, Leaderboards, Packs and Daily Challenge tabs.
